# ENAKS website — Codex execution brief

## Goal
Finish, deploy, and maintain a real mobile-first website for **ENAKS Auto and Transportations LLC** on a **dedicated GitHub repository**, **Netlify**, and the owner's Namecheap domain.

## Preserve
- Highway guide-sign design (Nov 2026): green #00694F sign hero with exit-tab CTA, Overpass type, light concrete #E9ECEA base, amber only for status. One motion moment (sign lights on load). Do not revert to the ivory/terracotta editorial look.
- All **11 services** in `public/services.html` with individual anchors.
- Home / Services / Government / Capabilities / Funding / About / Contact / Privacy (generated by build.py). Calls to action say "Ask about" or "Request", never "Book", until real booking exists.
- Keyboard-accessible responsive menu, good focus states, reduced-motion support and honest loading/error/success messages.
- No actual bookings are confirmed by the site. Contact forms are enquiries only.
- Do **not** include fabricated testimonials, regulatory certifications, insurance claims, fleet photos presented as real, service radii, or staff (owner-approved phone and email are published).
- Do not ask customers for PHI or use this form for emergency response.

## Priorities
0. Edit build.py / src/, run `python3 build.py && npm test`, commit public/ with the change.
1. Verify all responsive routes at 390px, 768px, 1440px and keyboard navigation; fix issues.
2. Link a dedicated GitHub repo. **Never modify RevenueOS.**
3. Import repo into Netlify, verify preview site and all page assets; no custom DNS changes before approval.
4. Set up verified Resend sender and inbox via Netlify environment variables; never commit credentials; test with a synthetic enquiry.
5. Add anti-spam Turnstile + persistent rate limiting before high-volume marketing.
6. After the owner shares exact Namecheap domain and confirms DNS changes, connect the domain using Netlify's actual records and verify HTTPS without damaging current MX records.
7. Replace unverified business facts with verified real contact info, hours, location and capabilities.
8. Add accessible, real scheduling only once actual booking process and availability are specified.
9. Record QA checks, live screenshots, endpoint delivery evidence, and deployment URL in the PR/commit notes.

## Completion gates
- All 8 routes load, assets resolve, mobile nav works with mouse and keyboard, no horizontal overflow.
- Request endpoint validates fields, rejects bot traps and invalid payloads, fails closed when email missing, sends successfully with configured Resend.
- Website publicly launched only after business approves factual details, privacy handling and custom domain rollout.

This is a commercial website. **Avoid deploying on Vercel Hobby**, which restricts commercial use. Netlify Free supports commercial websites subject to usage limits.
